# Codex对话时长与开发完成字段

## 1. 执行位置

只在`/go 完成开发:任务=<开发任务ID>`中执行，并且必须满足：

```text
全部适用仓库MR已经合并
且 已记录每个MR关联当前需求和开发任务的尝试结果
且 第二轮验证和Bug闭环已经通过
```

字段写入和任务完成顺序固定为：

```text
确定实际完成时间
→ 枚举关联Codex任务和分段
→ 汇总主动执行秒数
→ 换算分钟和小时
→ 写入并回读两个字段
→ 保存审计证据
→ 开发任务进入已完成
```

任一统计或字段门禁失败时，不把开发任务改为`已完成`。

## 2. 实际完成时间

1. 从当前开发任务、需求、分支、提交、MR创建记录和本次执行证据枚举全部适用MR；不要求关联成功。
2. 验证每个MR目标分支正确并已经合并；不读取或要求评审、CI、讨论状态。
3. 读取每个MR的可信`merged_at`时间戳。
4. 多仓库场景取所有适用MR中最晚的`merged_at`；单仓库取该MR的`merged_at`。
5. 按云效项目时区转换后写入开发任务字段`实际完成时间`。
6. 回读字段并与来源时间戳比较。

禁止使用当前命令时间、最后提交时间、流水线时间、第一条MR合并时间或手工估算时间替代。

## 3. Codex任务关联规则

枚举当前可访问的Codex任务，只有满足以下任一证据的任务或分段才能计入：

- `/go 开始开发:任务=<当前开发任务ID>`。
- `/go 完成开发:任务=<当前开发任务ID>`。
- `修复bug:<BUG-ID>`且该Bug正式关联当前开发任务。
- 批量目标中明确记录了当前开发任务ID的独立执行分段。
- Codex任务目标、结构化交接或云效开发任务评论中保存了双方任务ID的明确映射。

只有需求编号、相似标题、相同仓库、相同分支或同一负责人不足以建立关联。每条计入记录必须保存：

```text
Codex任务ID
Codex任务标题或目标
关联依据
分段ID（若有）
主动执行开始/结束检查点
主动执行秒数
```

按`Codex任务ID + 分段ID`去重。重试和续跑可分别计入不同分段，但同一秒数区间不得重复。

## 4. 时长口径

优先读取Codex平台或目标元数据提供的主动执行时长秒数，包括模型推理、工具执行和当前开发节点内的有效处理时间。

不计入：

- 等待用户输入、验证码、审批或外部人员评审的空闲时间。
- 任务暂停、归档或无人操作期间的时间。
- 与当前开发任务无关的对话分段。
- 已在其他分段计入的重复时间。

不得用首条消息到末条消息的自然时间差代替主动执行时长。若平台只提供自然时间跨度而无法取得主动执行时长，停止填写实际开发工时并说明能力缺口。

一个Codex任务只处理当前开发任务时，可以使用该任务的全部主动执行时长。一个Codex任务同时处理多个开发任务时，必须使用批量处理器记录的逐项开始/结束检查点或平台分段时长；无法分段时停止，不能把整段时长复制给每个开发任务。

## 5. 分钟和小时换算

先汇总全部去重后的原始秒数，再统一换算，不能逐任务先四舍五入：

```text
总秒数 = Σ每个有效任务或分段的主动执行秒数
总分钟数 = max(1, floor((总秒数 + 30) ÷ 60))，仅在总秒数>0时
未舍入小时 = 总分钟数 ÷ 60
云效实际开发工时 = 未舍入小时按HALF_UP保留2位小数
```

示例：

```text
30分钟 → 0.50小时
60分钟 → 1.00小时
95分钟 → 1.58小时
125分钟 → 2.08小时
```

云效字段单位必须确认是小时。字段必须接受至少两位小数；若字段只接受整数、单位不明或写入后精度与预期不一致，停止任务完成并报告配置问题，不静默向上取整为整小时。

## 6. 写入和审计

向当前开发任务写入：

```text
实际完成时间 = 最晚适用MR合并时间（项目时区）
实际开发工时 = 换算后的两位小数小时
```

在任务评论或可审计结构化字段中保留：

```text
[开发完成统计]
开发任务=<DEV-ID>
适用MR及merged_at=<列表>
实际完成时间=<项目时区时间>
Codex任务/分段=<去重列表>
总秒数=<整数>
总分钟数=<整数>
换算=<总分钟数>/60=<未舍入小时>
写入实际开发工时=<两位小数小时>
统计时间=<ISO时间>
```

写入后重新读取两个字段和审计记录。回读不一致、部分成功或重复统计时停止，不修改任务状态。重试时复用同一来源集合和幂等键：

```text
项目ID + 开发任务ID + complete_time_accounting
```

新增Codex执行分段后允许重新汇总并覆盖旧统计，但必须保留前后差异和新增来源；不得无证据手工改数。
